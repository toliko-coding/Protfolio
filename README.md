# Portfolio

Personal software engineering & cybersecurity portfolio, built as a synchronized terminal + file explorer over a virtual filesystem instead of a conventional scrolling page.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS

Long-form content (e.g. CyberSecurity write-ups) is planned to move to MDX once that content exists — not wired in yet.

## Development

```bash
npm run dev        # start the dev server
npm run build      # production build
npm run lint       # lint
npm test           # unit/component tests (Vitest)
npm run test:e2e   # end-to-end tests (Playwright) — starts its own dev server if one isn't already running
```
